# 홀로워크 추천기

홀로라이브 드림즈의 홀로워크 출전 멤버와 완료 횟수를 관리하는 브라우저 도구입니다.

## 주요 기능

- 8시간·10시간 홀로워크 추천 명단을 각각 관리
- 고정 멤버와 자동 추천 멤버 구성
- 홀로워크 완료 횟수와 업적·그린 큐브 현황 계산
- 홀로워크 보상표 제공
- 브라우저 로컬 저장 및 JSON 백업·복원

## 데이터 저장

입력한 데이터는 서버가 아니라 사용 중인 브라우저의 `localStorage`에 저장됩니다. 다른 기기나 브라우저로 옮길 때는 페이지의 **백업 내보내기**와 **백업 불러오기**를 이용하세요.

- 아이템 이미지: hololive Dreams 비공식 데이터베이스
