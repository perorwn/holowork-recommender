홀로워크 업적 추천기

1. holowork.html을 더블클릭해 실행합니다.
2. 모든 이미지는 images 폴더의 로컬 파일을 사용하므로 인터넷 없이도 표시됩니다.
3. 데이터는 브라우저에 자동 저장됩니다.
4. 백업 내보내기/불러오기로 다른 브라우저나 PC로 옮길 수 있습니다.
5. 노래 방송/게임 실황/녹음/잡담 방송 중 원하는 행을 클릭한 뒤 멤버를 고정합니다.
6. 각 행은 고정 멤버와 자동 추천 멤버를 합쳐 5명으로 채워집니다. 자동 추천 멤버는 파란 외곽선으로 표시됩니다.
7. 각 방송 유형 행에는 고정 멤버를 최대 5명까지 넣을 수 있습니다.
8. 모든 멤버 카드의 −/+ 버튼으로 완료 횟수를 조절할 수 있습니다.
9. 8시간 보내기는 노래 방송+게임 실황 10명, 10시간 보내기는 녹음+잡담 방송 10명을 각각 1회 올립니다.
10. 각 그룹의 마지막 전송 시간과 별도의 마지막 보내기 취소 기능이 제공됩니다.
   8시간 전송 영역은 노래 방송 위에, 10시간 전송 영역은 녹음 위에 표시됩니다.
11. '초기 데이터 빠른 입력'에서는 토키노 소라부터 차례로 횟수를 입력할 수 있습니다.
12. 숫자를 입력하고 Enter를 누르면 자동 저장 후 다음 멤버로 이동합니다.
13. 업적 현황에서 단계별 달성 인원과 획득한 그린 큐브를 확인할 수 있습니다.
14. 8시간·10시간 구성별로 앞으로 N회 보냈을 때 추가 획득할 큐브를 계산합니다.
